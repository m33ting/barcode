How it works

Every time a new barcode is detected, the scanner adds that barcode to the list and generates a random price between £0.50 and £50.00. The same barcode can be scanned again after it leaves the camera view.

Camera access normally requires HTTPS or localhost. This version uses ZXing, following the scanner approach in the code you provided.
